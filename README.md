# 두두 프롬프터 (Dudu Teleprompter)

대본을 띄워 놓고 카메라로 녹화할 수 있는 웹 텔레프롬프터입니다.

- 대본 붙여넣기, 자동 스크롤
- 글자 크기 · 스크롤 속도 · 배경 어둡기 조절
- 좌우 반전(거울 모드), 시선 기준선
- 전면 · 후면 카메라로 녹화 후 저장
- 한국어 · 영어 · 러시아어 전환 (상단 KO / EN / RU, `?lang=en` 처럼 URL로도 지정)

## 사용

https://parkseongdu-sketch.github.io/dudu-teleprompter/

아이폰 · 아이패드 사파리에서 열고 **공유 → 홈 화면에 추가**를 하면 앱처럼 쓸 수 있습니다.
카메라 녹화는 `https://` 주소에서만 동작합니다.
